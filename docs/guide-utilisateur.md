# KnowList en une page

**Se connecter** — avec l’identifiant et le mot de passe donnés par l’administrateur (ou via ton lien d’invitation).
La première fois, choisis ton propre mot de passe (12 caractères minimum ; une phrase comme `tulipe-orage-carnet` est idéale).

**Créer un set** — bouton **＋ Nouveau set**. Donne un titre, choisis les langues, puis tape tes cartes :
`Entrée` passe du terme à la définition puis à la carte suivante, `Maj+Entrée` va à la ligne, `Ctrl+Z` annule.
La flèche ⌄ d’une carte ajoute un exemple, une note, une image ou un son. **Importer** accepte un copier-coller depuis Quizlet
ou un tableur (tabulation, virgule, tiret… au choix) et les fichiers CSV/TSV/JSON.

**Étudier** — ouvre un set et choisis un mode :

| Mode | Principe |
|---|---|
| 🃏 Cartes mémoire | Retourne la carte (clic, `Espace`, ou touche) ; « Je savais » `→` / « Je ne savais pas » `←`, ou balaie à droite/gauche. |
| 🌱 Apprendre | QCM puis réponse écrite ; les cartes ratées reviennent plus souvent jusqu’à ce que tout soit acquis. |
| 📝 Test | Contrôle noté : vrai/faux, QCM, réponses écrites et association. |
| ⏱️ Association | Relie termes et définitions le plus vite possible ; bats ton record. |
| ✍️ Écriture | Écris la réponse ; majuscules, accents et petites fautes peuvent être tolérés (Options). |
| 🎧 Écoute | Le mot est lu à voix haute : écris ce que tu entends. |

Le bouton **Options** permet d’inverser le sens (définition → terme, ou mélangé), de mélanger, de limiter aux cartes ⭐ étoilées
ou difficiles, et de choisir le nombre de questions.

**Réviser chaque jour** — l’accueil affiche les **cartes à réviser aujourd’hui** : KnowList les fait revenir au bon moment
(répétition espacée). Fixe un objectif quotidien dans ton profil et entretiens ta série de jours.

**Partager** — menu « ⋯ » d’un set → *Partager* avec une personne du site (lecture seule ou modification) ou activer le lien interne.
On peut toujours **copier** un set partagé dans ses propres sets. Le menu propose aussi l’export CSV/TSV/JSON, l’impression PDF
et l’historique des versions.

**Sur téléphone** — dans le navigateur, « Ajouter à l’écran d’accueil » installe KnowList comme une application. Sans réseau,
tu peux continuer à réviser les sets déjà ouverts : tes réponses se synchronisent au retour de la connexion.

**Confort** — Profil : thème clair/sombre/automatique, réduire les animations, police adaptée à la dyslexie, double authentification,
export de toutes tes données, suppression du compte. Appuie sur `?` pour la liste des raccourcis clavier.
